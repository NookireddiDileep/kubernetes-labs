# Day 1

## Objective

Set up a Kubernetes learning environment and validate the cluster.

---

## Activities Completed

- Installed K3s
- Verified Kubernetes cluster
- Verified Node status
- Verified system pods
- Configured GitHub repository
- Started Kubernetes documentation

---

## Commands Practiced

- kubectl get nodes
- kubectl get pods -A
- kubectl cluster-info
- kubectl version

---

## Key Learnings

- K3s provides a lightweight Kubernetes distribution.
- containerd is the container runtime.
- CoreDNS enables service discovery.
- Metrics Server provides cluster metrics.
- Traefik acts as the default ingress controller.
